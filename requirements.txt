# Pinned exactly. Previously 17 of 19 entries used a bare `>=`, so every Railway
# rebuild resolved fresh and a yanked or compromised transitive release landed in
# production with no review gate. Dependabot (.github/dependabot.yml) opens the
# bump PRs, grouped so a routine patch wave is one reviewable diff.
#
# THE NUMPY/PANDAS PINS ARE NOT INDEPENDENT. pandas-ta 0.4.71b0 (required by the
# RL feature pipeline) pins numba==0.61.2, which requires numpy<2.3, and
# itself requires numpy>=2.2.6. The only valid numpy window is therefore
# [2.2.6, 2.3). Moving numpy to 2.3+ makes the whole file unresolvable, which is
# what CI caught on the first run of these pins.
#
# pandas-ta is unmaintained (0.4.71b0 is a pre-release) and has no 1.x, so it is
# held at the exact version the trained feature columns were built with. pandas
# is likewise held on the 2.x line: pandas-ta 0.4.71b0 predates pandas 3 and is
# not compatible with it.
#
# The RL stack pins are verified by CI on a clean runner, not locally — the
# machine this was authored on had no disk for torch.
